# rule-explorer-data

Static data files for the [Detection Rule Explorer](https://elena6918.github.io/rule-explorer/) demo.

Served via GitHub Pages. Fetched client-side by the explorer — not intended for direct browsing.

| Path | Contents |
|---|---|
| `sigma/index.json` | Search index for all Sigma rules |
| `sigma/{lineage_id}.json` | Full timeline for one Sigma rule |
| `ssc/index.json` | Search index for all SSC rules |
| `ssc/{lineage_id}.json` | Full timeline for one SSC rule |
